# Gestión hospitalaria — Java

Proyecto académico de Programación II, Tecnicatura en Programación (UTN).

## Funcionalidades
Modelado de pacientes, médicos, departamentos, salas, historias clínicas y citas. Programación de turnos con validación de fecha, costo, especialidad y disponibilidad del médico y de la sala.

## Tecnologías y conceptos
Java, programación orientada a objetos, herencia, interfaces, enumeraciones, colecciones, excepciones y relaciones bidireccionales.

## Ejecución
El proyecto NetBeans está configurado para JDK 26. Abrir la carpeta del proyecto en NetBeans y ejecutar `org.jcr.MainPruebas`.

El archivo `MainPruebas.java` contiene el verificador provisto para la evaluación académica; se conserva sin modificaciones. La ejecución informa verificaciones correctas y fallidas por consola.

## Alcance
Implementación en memoria, sin interfaz gráfica ni conexión a MySQL. El proyecto de Base de Datos es independiente. La compilación no fue verificada durante esta preparación del repositorio.
